# Security Policy

## Supported versions

Only the latest published `@mtilabs/ui` release is supported. Security fixes are released as a new patch version, not backported.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities. Instead, use GitHub's [private vulnerability reporting](https://github.com/mtilabs/mtilabs-ui-kit/security/advisories/new) for this repository.

Include:

- A description of the vulnerability and its impact.
- Steps to reproduce, or a minimal reproduction.
- The affected `@mtilabs/ui` version.

We'll acknowledge reports as soon as possible and follow up with a fix and coordinated disclosure timeline.
